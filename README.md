
# 🔫 Shooter Pad Game

A simple 2D browser shooting game built using **HTML**, **CSS**, **JavaScript**, and **jQuery**.
Control the shooter pad, destroy incoming enemies, score points, and survive through multiple difficulty levels.

---

## 🎮 Features

* 🔫 Player shooting system
* 👾 Enemy spawning system
* 🚀 Multiple game levels
* 🎯 Real-time score tracking
* ⚡ Smooth animations using `requestAnimationFrame()`
* 🎨 Dynamic level backgrounds
* 💀 Game Over system
* 🕹️ Keyboard controls

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* jQuery

---

## 🎯 How to Play

| Key           | Action     |
| ------------- | ---------- |
| ⬅ Left Arrow  | Move Left  |
| ➡ Right Arrow | Move Right |
| ⬆ Arrow Up    | Shoot      |
| Space Bar     | Shoot      |

---

## 🚀 Gameplay

* Enemies fall from the top of the screen
* Shoot enemies before they reach the bottom
* Each enemy destroyed gives points
* If an enemy reaches the bottom, the game ends

---

## 🧩 Difficulty Levels

| Level | Enemy Speed | Spawn Rate | Difficulty |
| ----- | ----------- | ---------- | ---------- |
| 1     | Slow        | Slow       | Easy       |
| 2     | Medium      | Medium     | Normal     |
| 3     | Fast        | Fast       | Hard       |
| 4     | Very Fast   | Very Fast  | Extreme    |
